TOPOLOGÍA HÍBRIDA EN ESTRELLA

Cinco sedes regionales convergen en un nodo central WAN (MOVISTAR), con switches Cisco 2960-24TT y routers de borde 2811 en cada sitio.

ENLACE TRONCAL IEEE 802.1Q

Cada router de borde segmenta su interfaz física FastEthernet en subinterfaces virtuales usando encapsulación dot1Q para el tráfico inter-VLAN.

ENLACES WAN /30

Los segmentos punto a punto entre MOVISTAR y cada sede utilizan máscara /30 (10.0.0.0–10.0.0.19) para minimizar el desperdicio de IPs en los enlaces de tránsito.

METODOLOGÍA CISCO PPDIOO

El diseño siguió las seis fases: Preparación → Planificación → Diseño → Implementación → Operación → Optimización.

06 — CONFIGURACIÓN IOS

Scripts de Cisco IOS

SW_SDK_DEV — Cisco 2960-24TT 
! ── Creación de VLANs empresariales
vlan 10
 name Administracion_PCs
vlan 30
 name Wireless_LAN
vlan 40
 name Servidores_Locales
vlan 99
 name Gestion_Nativa

! ── SVI de administración remota
interface vlan 99
 ip address 192.168.10.242 255.255.255.240
 no shutdown
ip default-gateway 192.168.10.241

! ── Puertos acceso VLAN 10 (PCs e impresoras)
interface range fastethernet 0/3-11
 switchport mode access
 switchport access vlan 10
 spanning-tree portfast

! ── Enlace troncal hacia el Router de Borde
interface fastethernet 0/1
 switchport mode trunk
 switchport trunk native vlan 99
 switchport trunk allowed vlan 10,20,30,40,99
 no shutdown

! ── Activar interfaz física del router
interface fastethernet 0/1
 no shutdown

! ── Subinterfaz VLAN 10 — Administración
interface fastethernet 0/1.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.128

! ── Subinterfaz VLAN 30 — Inalámbrico
interface fastethernet 0/1.30
 encapsulation dot1Q 30
 ip address 192.168.10.193 255.255.255.224

! ── Subinterfaz VLAN 40 — Servidores
interface fastethernet 0/1.40
 encapsulation dot1Q 40
 ip address 192.168.10.225 255.255.255.240

! ── Subinterfaz VLAN 99 — Gestión Nativa
interface fastethernet 0/1.99
 encapsulation dot1Q 99 native
 ip address 192.168.10.241 255.255.255.240

! ── Excluir IPs estáticas críticas del pool
ip dhcp excluded-address 192.168.10.1   192.168.10.25
ip dhcp excluded-address 192.168.10.193 192.168.10.195
ip dhcp excluded-address 192.168.10.225 192.168.10.230
ip dhcp excluded-address 192.168.10.241 192.168.10.245

! ── Pool para VLAN 10 — Área de Trabajo Cableada
ip dhcp pool POOL_VLAN_10
 network 192.168.10.0 255.255.255.128
 default-router 192.168.10.1
 dns-server 192.168.10.226

! ── Pool para VLAN 30 — Segmento Inalámbrico
ip dhcp pool POOL_VLAN_30
 network 192.168.10.192 255.255.255.224
 default-router 192.168.10.193
 dns-server 192.168.10.226

08 — CIERRE

Conclusiones Técnicas

🔒

SEGMENTACIÓN DE TRÁFICO

La división por VLANs reduce significativamente las colisiones lógicas y mejora el ancho de banda disponible en cada sede, aislando dominios de broadcast por tipo de servicio.

💡

RENTABILIDAD HARDWARE

Router-on-a-Stick elimina la necesidad de interfaces físicas dedicadas por VLAN, representando un ahorro sustancial en costos de adquisición de hardware corporativo.

📡

DHCP CENTRALIZADO

La consolidación de pools DHCP con exclusiones estáticas garantiza que servidores e impresoras críticas mantengan IPs fijas, evitando conflictos de direccionamiento.

📈

ESCALABILIDAD VLSM

El método VLSM permite incorporar nuevas sedes o subredes con mínimo rediseño del plan de direccionamiento, asegurando sostenibilidad a largo plazo de la infraestructura.
